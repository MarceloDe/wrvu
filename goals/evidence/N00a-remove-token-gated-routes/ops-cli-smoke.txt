## Blocked — the credentialed run

The node's verify line is:

    node scripts/ops/clerk-admin.mjs --list-allowlist    # succeeds locally

To run it for real, the production Clerk key was pulled locally:

    cd /Users/mfelix/projects/wruvs
    vercel env pull --environment=production --yes <scratchpad>/.env.prod   # OK, 45 vars

but the invocation that consumes it:

    node --env-file=<scratchpad>/.env.prod scripts/ops/clerk-admin.mjs --list-allowlist

was refused by the sandbox permission classifier. No workaround was attempted. Sections
1-5 above exercise every code path of that command except the 200 response body itself.

To close it, an operator or the Validator runs, on a machine with the key:

    vercel env pull .env.local
    node --env-file=.env.local scripts/ops/clerk-admin.mjs --list-allowlist

and confirms a JSON `{ "allowlist": [...], "count": N }` plus a new `"outcome":"ok"` line
in goals/evidence/ops-audit.jsonl.
